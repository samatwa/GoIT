# Argo CD coursework

This project contains Argo CD application definitions and Kubernetes namespace manifests.

- `application.yaml` — application definition.
- `monitoring-application.yaml` — monitoring application definition.
- `monitoring/` — Grafana, Loki and Prometheus application configurations.
- `namespaces/` — application, infrastructure-tools and monitoring namespaces.

Review repository URLs, branch names, cluster destinations and namespace requirements before applying these historical configurations to a live cluster. Current project files are maintained in the GoIT collection; original Git refs are listed in [HISTORY-MANIFEST.json](../../HISTORY-MANIFEST.json).
